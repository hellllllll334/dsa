# Behind QOU Spear Kill (Fabric 1.20.4)

Client-side mod. Toggle with **Right Shift** (rebindable in Controls).

Requirements: Fabric Loader 0.15+, Fabric API, an Elytra in the chest slot.
Equip the elytra, jump to start gliding, then press the toggle key.

## Build with GitHub
Push this folder to a repo. The "Build mod jar" workflow (Actions tab) uploads the
jar as an artifact. Use the jar that does not end in `-sources`.

## Build locally
    gradle build      # Gradle 8.5+, JDK 17
